# Security policy

House Planner handles private construction records, financial data, receipts, and photographs. Please do not open a public issue containing credentials, invitation tokens, project documents, personal information, or vulnerability details.

Report security concerns privately to [carlosan1708@gmail.com](mailto:carlosan1708@gmail.com). Include the affected area, reproduction steps, and impact without attaching real project data.

Only the latest release is actively maintained. Authentication and authorization bypasses, unintended public-file exposure, destructive data operations, and cross-project access are treated as priority issues.
