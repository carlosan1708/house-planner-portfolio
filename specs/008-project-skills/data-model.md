# Data model

> Historical private-development record. Its commit IDs are metadata only; the original commit objects and review evidence are retained privately and are not part of this public snapshot. See [snapshot provenance](../../docs/portfolio/snapshot.md).

No application data changes. Four namespaced skill folders each contain name/description frontmatter and an automatically discoverable UI interface. Git output: one current-date foundation commit, a bijective original-to-reconstructed SHA mapping, preserved author/committer headers and parent topology, declared skill/guide/AGENTS overlays, and a local verification report. Existing historical evidence remains tied to original SHA values.
