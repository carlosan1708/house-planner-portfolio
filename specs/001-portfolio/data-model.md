# Artifact model

> Historical private-development record. Its commit IDs are metadata only; the original commit objects and review evidence are retained privately and are not part of this public snapshot. See [snapshot provenance](../../docs/portfolio/snapshot.md).

No production collections, routes, or API payloads change for portfolio documentation.

| Artifact | Identity and relationships | Validation |
|---|---|---|
| Requirement | FR-001 through FR-012 in the feature spec | Every ID appears in task/evidence mapping |
| Task | T001 onward, mapped to user story and requirement | Unique ID, checkbox state, exact artifact path |
| Design case | Retrospective status, requirements, code/tests, limits | No claim of prior spec-first chronology |
| History correspondence | Original SHA → rewritten SHA, original parent mapping, author/committer/time | All original commits represented; only policy-defined files differ |
| Synthetic model | Schema version 1, invented rooms/fixtures, fictitious source IDs | Existing parseHouseModel validates it; no client source geometry |
| Validation record | Command, outcome, environment, omissions, convergence | Results from actual execution; no inherited remote CI claims |

History mapping, original file fingerprints, and recoverable bundles stay offline outside this
repository. Their publication-safe summary contains counts and transformation categories only.
