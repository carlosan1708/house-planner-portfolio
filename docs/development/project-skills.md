# House Planner project skills

These repository skills complement the installed Spec Kit workflow; they do not replace specifications or grant permission for external actions. Codex discovers them in .agents/skills. New chats can invoke the names below explicitly.

| Skill | Use |
|---|---|
| `$house-planner-release` | Backup, exact-source CI/candidate gates, normal merge and verified production promotion |
| `$house-planner-qa` | Choose focused unit/browser/emulator/manual evidence and keep synthetic sessions isolated |
| `$house-planner-access-review` | Trace project, role, read-link, folder, vault and platform-owner boundaries |
| `$house-planner-mobile-ux` | Review discoverability, canonical navigation, touch controls, dialogs and responsive flows |

Read the relevant SKILL.md rather than loading every skill for each task. Complete regressions and actions that automatically trigger them require the explicit approval recorded in root AGENTS.md. A general deploy/merge/test instruction does not supply it. These documentation changes were checked with skill/link validators and deterministic Git-object comparisons, not an application regression.

See [foundation provenance](../../.agents/project-skills-provenance.md) for the authorship date, reconstructed presentation history, archived source cutoff and evidence limits. Operational main and the existing archive remain separate from that local reconstruction.
