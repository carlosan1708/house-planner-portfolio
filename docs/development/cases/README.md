# Reconstructed design cases

These three cases were reconstructed on 2026-10-13 by reading the existing implementation and
tests. They explain current contracts and trade-offs; they are not evidence that specifications
were written before those features were developed.

| Case | Design question |
|---|---|
| [Assistant](assistant.md) | How can a model use permitted project evidence and propose edits without publishing them? |
| [Workbook approval](workbook-approval.md) | How can members edit private copies while preserving official workbook authority? |
| [Encrypted documents](encrypted-documents.md) | How do separate grants and temporary unlocks protect content across all integration paths? |

For a change that follows the newly adopted kit from the beginning, inspect the
[portfolio specification](../../../specs/001-portfolio/spec.md) and
[requirement-to-validation trace](../../../specs/001-portfolio/traceability.md).
