# Public snapshot sanitation scope

**Scope:** the files in this fresh public portfolio snapshot. The original private Git history is
not part of this repository. This report supersedes the earlier curated-archive report for the
purpose of this public copy; it does not certify the private operational repository for publication.

## Preparation

- Exported reviewed current source without importing `.git`, original branches, tags, PRs or logs.
- Replaced client/project labels, real workbook keys, operational Firebase/GCP identifiers, browser
  configuration, billing identifiers and notification/administrator examples with synthetic values.
- Preserved the public author credit, security contact and explicitly linked author-hosted demo.
- Retained fictional demo workbooks, images and invented model geometry. The historical real budget
  workbook and plan-specific generator are absent from the snapshot and its new Git history.
- Kept production deployment ownership in the original private repository. Public scripts use
  placeholder policy identities and public workflows cannot deploy to that installation.
- Labeled prior specification artifacts as historical private records. Original commit objects are
  not imported to make those records look locally reproducible.
- Added verified-mailbox invitation boundaries and disabled live AI by default in this public copy.
- Added the permission-required application license while preserving upstream notices.

## Verification and limits

[Snapshot validation](validation.md) records the checks actually run for this public copy. Demo
workbooks were inspected for private identifiers, external links, macros and comments; image
metadata was reviewed. A local credential-pattern scan supplements, but does not replace,
review of the files and deployment boundary.

A source review does not establish live production IAM/rules, independent model quality, email
or Sheets behavior, or absence of every possible unknown secret format. The original private
repository and its GitHub surfaces were deliberately not made public or rewritten.
